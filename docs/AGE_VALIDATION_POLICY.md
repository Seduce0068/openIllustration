# 国別成人年齢検証ポリシー (Cross-Border Age Validation Policy)

本ドキュメントは、国境を越えた成人年齢の差異に対応するための動的な年齢検証ロジックを定義する。

## 1. 原則

本システムは、ユーザーの「居住国」に基づき、その国で成人（または成人向けコンテンツへのアクセスが許可される年齢）に達しているかを動的に判定する。

## 2. 判定ロジック

Rust バックエンドの認証ロジックにおいて、以下のマッピングテーブルを用いる。

| 国コード (ISO 3166-1) | 成人年齢/アクセス許可年齢 | 備考 |
| :--- | :--- | :--- |
| JP (日本) | 18歳 | 民法改正により18歳を成人とする |
| US (米国) | 18-21歳 | 州により異なるため、保守的に 21 歳とする |
| DE (ドイツ) | 18歳 | 刑法・青少年保護法に基づく |
| FR (フランス) | 18歳 | 成人法に基づく |
| (Default) | 18歳 | 未定義国は 18 歳を基準とする |

* **検証手順**:
    1. 提示された Verifiable Credential (VC) から `issuing_country` (または居住国クレーム) を取得。
    2. 上記のマッピングテーブルを参照し、当該国の閾値 `T` を決定。
    3. ユーザーの生年月日と現在時刻から算出した満年齢が `T` 以上であれば許可。

## 3. 実装上の注意 (Rust)

```rust
fn get_legal_age_threshold(country_code: &str) -> u32 {
    match country_code {
        "US" => 21,
        "JP" | "DE" | "FR" => 18,
        _ => 18, // デフォルトで 18 歳とする
    }
}
```

## 4. 法的リスク回避

* **保守的な閾値設定**: 各国で成人年齢が異なる場合や、州レベルで法律が異なる場合（例：米国）、プラットフォーム側は「最も厳しい基準（21歳）」を適用することで、法的トラブルを未然に防ぐ。
* **責任の所在**: ユーザーの居住国情報はユーザー自身が提示した VC に依存する。もしユーザーが居住国を偽って提示した場合、それはユーザー側の公的証明書に対する違反行為となり、運営者の故意過失を否定する証拠として扱う。
