# 年齢判定ポリシー（実装制約・未承認）

> **状態:** 現行の国コード閾値はコード上のプロトタイプです。法的助言・各国法の網羅・本人確認済み年齢の証明として使用しないでください。

## 1. 現行実装

`common/src/age.rs` は `JP`、`DE`、`FR` を18歳、`US`を21歳、それ以外を18歳とする単純なマッピングを実装しています。日付文字列から満年齢を計算します。国コードと生年月日は現在のAPI入力であり、モック環境では信頼された公的属性ではありません。

## 2. 未実装の検証

- 本人確認済み発行者からの生年月日・居住国属性取得。
- 発行者の信頼ルート、証明書パス、失効状態、提示署名、nonceの検証。
- 国・地域・コンテンツ種別に応じた適用法令の確認。
- 閏日等の境界日、未来日、国コード正規化、年齢閾値の更新手続の法務レビュー。

## 3. 本番化条件

年齢制限を本番で有効化する前に、対象地域・対象コンテンツ・適用閾値・信頼できる属性ソース・個人情報保持範囲を決定し、専門家レビューと境界値テストを完了してください。値を安全側とみなす根拠なしに「保守的」「法的に安全」と表現しないこと。
