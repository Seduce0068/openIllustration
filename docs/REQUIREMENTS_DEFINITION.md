# 要求定義書 (Requirements Definition)

本ドキュメントは「分散型デジタル美術館（ギルド）」の要求定義を定めたものである。

## 1. 目的
国境やプラットフォーム検閲に依存しない、技術的・法的堅牢性を備えた静止画専門のデジタル美術館プロトコルを構築する。

## 2. ゴール
* セキュリティと真正性を数学的に証明できる、個人の趣味レベルで運用可能なプロトコルを公開すること。
* 運営者による恣意的な検閲を排除し、透明性の高い適正プロセス（Due Process）に基づくモデレーションを実現すること。

## 3. 主要要求事項
* **真正性の強制**: JPKI（公的個人認証）を用いた物理的・数学的な本人確認。
* **完全 Rust スタック**: バックエンドからインフラ操作スクリプトまで全て Rust で統一。
* **分散ガバナンス**: 陪審制およびブロックチェーンログによる客観的なモデレーション。
* **法的抗弁**: AGPLv3 による思想の強制と、JPKI 電子署名による否認防止（Non-Repudiation）の確保。
* **ユーザー負担**: 認証・決済コストを全てユーザーへ外部化する。
