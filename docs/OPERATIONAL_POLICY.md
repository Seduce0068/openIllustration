# 運用ポリシー (Operational Policy)

本ドキュメントは、本システムを利用したギルド運用における決済および認証の制約を定義する。

## 1. 決済ポリシー (Strict P2P Policy)
本システムは、いかなる金銭および電子決済手段（JPYC、USDC等）も保持・媒介しない。

* **P2P 強制**: クリエイターへの対価支払いは、ファンからクリエイターの公開ウォレットアドレスへの直接送金のみを許可する。
* **媒介の排除**: システム（バックエンドおよびスマートコントラクト）は、送金の成否、金額の検証、手数料の徴収に一切関与しない。
* **表示機能**: UI 上で表示されるのは、クリエイターのアドレスと、送金用 QR コード/ディープリンクのみとする。

## 2. 認証ポリシー (Regional Identity Verification)
本システムへの入場は、居住国に応じた公的デジタル身分証の検証を必須とする。

* **国内ユーザー (JPKI)**:
    * デジタル庁認定の JPKI 準拠デジタル認証アプリを通じた認証を必須とする。
    * 署名用電子証明書（6-16桁のパスワード）による規約同意を必須とする。
* **海外ユーザー (ISO/OID4VP)**:
    * ISO/IEC 23220 および OID4VP に準拠した Verifiable Credentials (VC) の提示を必須とする。
    * 発行体（政府機関等）が信頼できる Root of Trust に登録されていることを条件とする。
* **年齢制限**: 国内・海外を問わず、JPKI または VC 内の生年月日データに基づき Rust バックエンドで厳格に 18 歳以上であることを判定する。

## 3. 免責と責任の所在
* **運営者の不関与**: 運営者は決済の媒介者ではなく、単なる「技術プロトコル（OSS）」の提供者である。
* **コンプライアンス**: 各ギルドの運営者は、自身の管轄地域における資金決済法および関連法規を遵守し、独自にモデレーションを行う責任を負う。
