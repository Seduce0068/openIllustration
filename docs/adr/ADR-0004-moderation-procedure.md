# ADR-0004: モデレーション手続

- Status: Accepted
- Date: 2026-11-02
- Approved: 2026-11-16（プロジェクトオーナーによる包括委任に基づくエージェント判断）
- Decision owners: Project owner
- Scope: 通報の受理から確定、異議、配信停止までの手続

## Context

現行実装は、通報されたコンテンツに対して3票が集まった時点で
`Approve` / `Reject` の多数決により状態を確定する。投票期間、投票資格、
同数時の扱い、異議申立て、BAN、IPFSのピン解除は未決定である
（`DOCUMENT_STATUS.md` の DEC-05）。

ADR-0001 は、反検閲性が違法・有害コンテンツ対応を無効化するものではない
とし、モデレーション手続、異議申立て、公開性、配信・ピン解除の責任を
定めることを求めている。

## Decision

以下を採用する。実装状況は「実装状況」節に記載する。

1. **投票資格**: 次をすべて満たす利用者に限る。
   - JPKI認証済みである。
   - BANされていない。
   - 対象コンテンツの投稿者でない。
   - 同一通報に対して未投票である。
2. **投票期間**: 通報受理から7日間。期限は `reports.deadline_at` に記録する。
3. **定足数**: 3票。期限までに3票未満の場合は通報を棄却し、
   コンテンツを `Approved` に戻す。
4. **確定**: 期限終了時に集計する。期限内の即時確定は行わない。
   これにより、反対意見を出す機会を確保する。
5. **同数**: `Reject` と `Approve` が同数の場合は `Rejected` とする。
   違法・有害コンテンツの公開継続リスクを避ける安全側の扱いである。
6. **異議申立て**: 確定から30日以内の再通報を異議として受理する。
   異議は新しい通報として審査し、元の確定を直接上書きしない。
7. **BAN**: 自動BANは行わない。重大な違法コンテンツ、繰り返しの違反、
   なりすましは、証跡を確認したうえで運営が判断する。
   BANの根拠と期間を監査ログに記録する。
8. **IPFSの扱い**: 確定後にPinataのピン解除を手動で行う。オンチェーンや
   他ゲートウェイからの削除は保証できない。削除要請には個別に対応し、
   再配布の停止を約束しない。
9. **公開性**: 通報件数、確定結果、理由の要約を公開する。
   通報者・投票者の識別情報は公開しない。
10. **監査**: 通報、投票、確定、異議、BAN、ピン解除を監査対象イベントとし、
    主体・時刻・理由・対象を含める。

### 実装状況（2026-11-16）

- **採用済み・実装済み**: 投票資格のうち JPKI 認証・BAN 検査・同一通報の重複投票拒否
  （API 検査＋DB 一意インデックス）。確定後の追加投票拒否。
- **採用済み・実装済み（本ADR整合のため変更）**: 同数時は `Rejected`。
  従来実装は同数時に `Approved` としていたが、本ADRの安全側判断に合わせて
  `Reject >= Approve` を `Rejected` とする。
- **採用済み・未実装（本番有効化の前提）**:
  - `reports.deadline_at` と7日間の投票期間、期限終了時の集計。
    現行は3票到達時に即時確定する暫定実装であり、本ADRの期限ベース確定に
    置き換えるまでモデレーションを本番運用しない。
  - 定足数未達時の通報棄却と `Approved` への復帰。
  - 異議申立て（確定から30日以内の再通報）。
  - BAN の根拠・期間の監査記録、ピン解除の監査記録。
  - 投票資格のうち「投稿者でない」の明示検査。
- 実装が本ADRに追いつくまで、モデレーション結果を本番の最終判断として
  扱わない（[DOCUMENT_STATUS.md](../DOCUMENT_STATUS.md) の DEC-05 を参照）。

## Consequences

- 確定まで最大7日かかり、緊急の違法コンテンツ対応は運営の手動判断に
  依存する。
- 定足数に達しない通報が増える可能性がある。
- 同数時に `Rejected` とすることで、誤削除のリスクと公開継続のリスクを
  天秤にかけ、公開継続側を重く見る。
- 異議を別通報として扱うため、同じコンテンツに複数の審査が並行し得る。
- BANとピン解除が手動であるため、運用負担と判断のばらつきが残る。

## Alternatives

- **3票即確定**: 迅速だが、反対意見の機会がなく、組織的な投票操作に弱い。
- **同数時に Approved**: 表現の自由を優先するが、有害コンテンツの
  公開継続リスクを高める。
- **自動BAN**: 誤検知時の影響が大きく、異議申立てと両立しない。
- **オンチェーン投票**: 透明性は高いが、投票者のプライバシーと
  コスト、Sybil耐性の問題が未解決である。

## Open Questions

- 投票者の選出方法（全利用者、ランダム陪審、専門家）。
- Sybil耐性と投票報酬の設計。
- 異議申立ての審査主体と最終判断者。
- 緊急削除の判断基準と事後承認の手続。
- 削除要請・法的命令への対応フロー。
- 公開する情報の範囲とプライバシー保護。
