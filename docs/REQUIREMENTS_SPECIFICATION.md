# 要件定義書 (Requirements Specification)

本ドキュメントは、要求定義書に基づき具体的なシステム要件を定義する。

## 1. 機能要件

### 1.1. 認証 (Auth)

* ユーザーはマイナンバーカード（JPKI）を用い、デジタル認証アプリ経由でデジタル署名を行いログインする。
* JPKIの「利用者証明用」「券面事項入力補助用」「署名用」の3つの暗証番号を必須とする。
* 年齢確認（18歳以上）はデジタル認証時に Rust 側で厳格に判定する。

### 1.2. コンテンツ配信 (Distribution)

* ファイル形式は JPEG XL (.jxl) に限定する。
* ブラウザ側でプログレッシブデコードを行い、高速表示を実現する。

### 1.3. 経済圏 (Finance)

* 決済は JPYC などの電子決済手段（ステーブルコイン）のみを受け付ける。
* 運営者は決済を媒介せず、スマートコントラクト上のクリエイターとファン間の P2P 送金をUI上で表示するのみとする。

### 1.4. モデレーション (Moderation)

* 通報が発生した際、陪審員（ランダム抽出）による投票プロセスを開始する。
* すべての判断プロセスはブロックチェーン上に署名付きログとして記録する。

## 2. 非機能要件

### 2.1. セキュリティ

* 運用者は生の個人情報を一切保持せず、ハッシュ値のみを識別子として扱う。
* 完全な Rust スタックにより、メモリ安全性を確保する。
* 決定論的ビルドにより、ソースコードとバイナリの同一性を数学的に証明する。

### 2.2. パフォーマンス

* Cloudflare Workers / R2 によるエッジコンピューティングで遅延を最小化する。

### 2.3. 法的適合

* AGPLv3 に従い、ネットワーク利用を含む改変コードの公開義務を負う。
* プロバイダ責任制限法に基づく削除申請は適正手続き（反論権の付与）を必須とする。
